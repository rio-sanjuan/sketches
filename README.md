# sketches

Small projects behind posts on [rio-sanjuan.dev](https://rio-sanjuan.dev): code that backs a
post but doesn't need a repo of its own.

Each folder is one project and stands on its own, with its own README (what it is, how to
run it, and a link to the post), its own dependencies, and its own tests. Python projects use
[uv](https://docs.astral.sh/uv/); TypeScript projects use npm. Nothing is shared between
folders, so any one of them can be copied out on its own.

A project moves to a repo of its own once it outgrows a folder.
